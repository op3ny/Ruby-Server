# O'que é o Ruby Auth

O Ruby Auth é um modelo para a criação de um sistema auth usando Sinatra, Sqlite3 e JsonWebTokens.

O projeto é totalmente inspirado no projeto da [Hsyst Org](https://github.com/Hsyst), o Hsyst Auth, mas o Ruby Auth é apenas um modelo, por isso há erros de ortografia, e umas gírias nos texto, um html básico, com apenas o necessário para criação do seu projeto usando esse modelo, fica a sua custódia editar do jeito que você quiser!

O projeto está com comentários completos, para você entender como funciona, além de como é quase igual ao Projeto Original da Hsyst, para ver a Documentação Técnica veja no repositório original da Hsyst ([@Hsyst/Hsyst-Auth](https://github.com/Hsyst/Hsyst-Auth.git)).
